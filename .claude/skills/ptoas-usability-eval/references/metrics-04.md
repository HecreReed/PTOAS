# `04 算子基本功能实现` 的 PTOAS 子集指标

这里只评估 PTOAS 真正覆盖到的“示例 / 编译 / 验证 / 反馈”链路，不把 PTOAS 当成完整算子研发平台。

说明：保留用户原始口径，`10 分制` 与 `100 分制` 混用，不强行归一。

## 先声明层级

`04` 子集同样先声明层级：

- `L1 文档审阅层`
- `L2 本地最小运行层`
- `L3 Linux compile-only 层`
- `L4 NPU 上板层`

未进入对应层级，只能标 `未实测`。
