# scripts/package/

Packaging and release scripts/templates for PTOAS. This directory is used to generate distributable artifacts.

## Layout (High Level)

- `package.py`: Main packaging entry script
- `pto_as/`: Package templates and helper scripts specific to PTOAS
- `latest_manager/`: Helpers for managing “latest” package versions
- `module/`: Module-level packaging descriptors
- `common/`: Shared helpers and configuration fragments
